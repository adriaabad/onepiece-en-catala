# One Piece en català · reproductor local

Una pàgina HTML local per veure els capítols disponibles a [One Piece Català](https://onepiece.xarxacatala.cat/) amb botons de capítol anterior i següent.

## Ús

1. Obre [`onepiece-catala.html`](onepiece-catala.html) amb Chrome, Edge o un altre navegador modern.
2. Prem **Reprodueix**. El reproductor comença al capítol 212, o al darrer capítol que hagis vist en aquest navegador.
3. Fes servir **Següent episodi**, **Anterior** o el camp **Capítol** per navegar.

L'opció de reproducció automàtica passa al capítol següent quan acaba el vídeo. Si el navegador impedeix iniciar-lo automàticament, prem **Reprodueix**.

La pàgina cobreix els capítols 207–492. El codi funciona localment, però els vídeos es reprodueixen des dels servidors de Xarxa Català i requereixen connexió a Internet. El botó **Obre a Xarxa Català** porta al capítol corresponent de la web original.

Aquest repositori no inclou cap vídeo ni cap imatge de la sèrie.
