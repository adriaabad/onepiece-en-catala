# One Piece en català · reproductor local

Una pàgina HTML local per veure els capítols disponibles a [One Piece Català](https://onepiece.xarxacatala.cat/) amb botons de capítol anterior i següent.

## Ús

1. Obre [`onepiece-catala.html`](onepiece-catala.html) amb Chrome, Edge o un altre navegador modern.
2. Prem **Reprodueix**. En la primera visita, el reproductor comença al capítol 1. Després recupera el darrer capítol que hagis vist en aquest navegador.
3. Fes servir **Següent episodi**, **Anterior** o el camp **Capítol** per navegar.

L'opció de reproducció automàtica passa al capítol següent quan acaba el vídeo. Pots indicar quants segons abans del final vols avançar per saltar l'outro (per exemple, `90`). Amb `0`, espera que el vídeo acabi. El valor es recorda en aquest navegador. Si el navegador impedeix iniciar el capítol següent automàticament, prem **Reprodueix**.

La pàgina cobreix els capítols 1–492. El codi funciona localment, però els vídeos es reprodueixen des dels servidors de Xarxa Català i requereixen connexió a Internet. El botó **Obre a Xarxa Català** porta al capítol corresponent de la web original.

Versió web: [obre el reproductor amb GitHub Pages](https://adriaabad.github.io/onepiece-en-catala/). La pàgina [`index.html`](index.html) obre el reproductor des de l'adreça principal del lloc.

Aquest repositori no inclou cap vídeo ni cap imatge de la sèrie.
